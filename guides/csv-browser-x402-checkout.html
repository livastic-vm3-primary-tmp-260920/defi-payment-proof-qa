How a sale is accounted for

  1. The free quote shows only the terms of one API call. It is not a receipt or an invoice.
  2. Only an independent buyer may connect their own Base wallet, read and approve a fixed EIP-3009 USDC authorization, and choose to call the original hosted merchant.
  3. The merchant must return an actual result. A browser HTTP 200 alone does not prove irreversible onchain payment, and a browser error does not prove the transfer failed.
  4. A sale is credited to the operator only if a distinct external Base USDC token transfer is independently finalized and linked to authorized delivery. No buyer orders are claimed for this new checkout.
