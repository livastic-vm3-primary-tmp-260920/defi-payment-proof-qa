Practical field problem

The difference between a 402 on curl and a paid browser buyer

  • Origin: Does the 402 response permit the browser's Origin?
  • Expose: Does it expose PAYMENT-REQUIRED and, on paid completion, PAYMENT-RESPONSE?
  • Preflight: Does a separate OPTIONS respond with 2xx and allow the intended method plus PAYMENT-SIGNATURE, Content-Type?
  • Paid delivery: Not tested here. A quote is not proof that a signed retry worked or that the buyer received the resource.

This independently observed problem is discussed in the x402 Foundation CORS issue #3722. A separate one-owner real browser positive-control field report shows a 402 quote and an OPTIONS 204 on our own VM5 API; it is not third-party buying evidence.

Important: JavaScript cannot directly set its own browser-generated Access-Control-Request-Headers preflight fields or see every server header.
