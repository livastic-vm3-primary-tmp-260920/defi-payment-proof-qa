    What's checked—and not checked

    The heuristic looks for missing document language, title, H1 and description, missing image alt attributes, duplicated IDs, local fragment links without matching IDs, placeholder links, target-blank rel warnings and heading level gaps. Decorative images with an explicitly empty alt attribute are not automatically treated as defects. Comments, script bodies and style bodies are excluded from source markup scanning. Findings are capped in the display, but totals are preserved.

    Not checked: semantic accessibility, keyboard interaction, actual rendered DOM, content accuracy, full HTML5 parsing, responsive layouts, security vulnerabilities or production compliance. This example does not load a remote URL and makes no payment or wallet request.
